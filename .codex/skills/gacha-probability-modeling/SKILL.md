# Gacha Probability Modeling

## Model Rules

- `目標機率`：每一抽獨立抽中目標的基礎機率；沒有被保底強制命中時使用這個機率。
- `目前已抽`：目前情境下已經累積的抽數，不只是保底進度。
- `接下來要抽`：使用者打算再投入的抽數，會加到 `目前已抽` 上。
- 主結果必須用累積抽數計算：`目前已抽 + 接下來要抽`。
- `啟用保底計算` 關閉時，除非 `目標機率` 正好是 `100%`，否則永遠不要顯示精準 `100%`。
- `啟用保底計算` 開啟時，每滿一個 `保底` 區間至少保證取得一個目標。
- 保底開啟時，只要 `floor(累積抽數 / 保底) >= 目標數量`，就必須顯示精準 `100%`。
- 機率極接近但不是保證時，顯示上界提示，例如 `>99%` 或 `>99.99%`，不要顯示精準 `100%`。
- 顯示文字要區分「幾乎必出」和「保證必出」；前者是近似值，後者才是 `100%`。

## Validation Cases

修改計算邏輯後，至少檢查這些情境：

- 無保底，`目標機率 = 0.7%`，累積 `100020` 抽，目標 `2` 個：不能顯示精準 `100%`。
- 啟用保底，`保底 = 200`，累積 `1020` 抽，目標 `1` 到 `5` 個：都應該顯示 `100%`。
- 啟用保底，`保底 = 200`，累積 `1020` 抽，目標 `6` 個：不能顯示保證 `100%`。
- 無保底，`目標機率 = 0%`：只有 `0 個` 的機率應該是 `100%`。
- 無保底，`目標機率 = 100%`：累積抽數以內的目標數量都應該是保證達成。
